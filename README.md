# Rick and Morty

Bu proje, Rick and Morty dizisinin karakterlerini listelemek için geliştirilmiş bir React Native uygulamasıdır. Proje, dizi hayranlarının karakterler hakkında detaylı bilgi edinmesini ve sezgisel bir kullanıcı deneyimi yaşamasını amaçlamaktadır.

# Özellikler

- Rick and Morty API kullanılarak karakter, bölüm ve mekan verilerinin çekilmesi.

- Karakterlerin detaylı bilgilerinin görüntülenmesi (isim, tür, durumu, kökeni vb.).

- Kullanıcı dostu ve responsive tasarım.

- React Navigation ile kolay gezinme.

# Kullanılan Teknolojiler

- React Native
- CLI
- Rick and Morty API (https://rickandmortyapi.com/)
- React Navigation
- Axios
- Redux
- React-native-safe-area-context
- React-native-screens
- Redux-thunk
- iconsax-react-native
